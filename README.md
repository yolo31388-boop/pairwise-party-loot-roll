# pairwise-party-loot-roll

五人队打完 Boss，队长看到三件装备，队员只看到一件，掉落表给每人各生成了一份实例；分配用的随机数在主线程取，回放时同一 seed 被复用，每次结果一样；需求与贪婪的优先级没有参与权重，贪婪的人拿走了本该需求的东西；离线玩家的权重仍然计入，分配时出现空缺；同一件装备被两个 roll 同时写进背包，数量变成两件；交易锁只在拾取时加，分配时绕过了锁；副本重置只清了怪物，掉落池里的旧条目还在；分配失败没有回滚，装备从地面消失但没进任何人背包；roll 点数没有记录，队员质疑时查不到；队长权限变更后旧队长仍能分配。gameplay/party_loot_roll.py 是核心，tests/test_party_loot_roll.py 15个红。要修的是：共享掉落池；服务端随机；每次新种子；权重含优先级；离线剔除；原子分配；统一加锁；重置清池；失败回滚；记录点数。

## 运行

```bash
python -m pytest tests -q
```

初始状态：15 个用例失败。修复实现使全部用例通过，不要修改 `tests/` 下的测试。
